# Claims

Status: Public scaffold. Release status: scaffolded. License pending human review.

## Allowed Claims While Scaffolded

- This repo is a public scaffold for public-safe PCB documentation review.
- It demonstrates review discipline around scope, schematic readability, power domains, signal classes, interfaces, manufacturing-readiness questions, evidence severity, and boundary handling.
- It uses synthetic examples unless an artifact is explicitly marked reviewed and approved for public use.
- It may support future draft Upwork proof for PCB documentation review and report cleanup after human review.

## Claims Requiring Human Review

- Any claim that a real PCB, KiCad project, schematic, layout, BOM, Gerber, pin map, or board image is public-safe.
- Any claim that this checklist was used on client work or production hardware.
- Any claim that findings represent engineering sign-off, compliance, safety, or manufacturing approval.

## Forbidden Claims

- Certification, safety certification, compliance approval, engineering sign-off, or manufacturing approval.
- Client results, customer files, production board source, production RIB implementation, production schematic/routing/BOM/Gerber/pin-map details, or private component strategy.
- Live Upwork offer copy, pricing, turnaround promises, guarantees, or client outcome claims.
