# File Policy

Status: Scaffolded. Human Review Required before publication.

## Allowed

- checklist templates;
- synthetic review examples;
- documentation gap notes;
- reviewed public-safe screenshots only after approval.

## Not Allowed

- client files;
- production KiCad source;
- schematics, routing, BOMs, Gerbers, exact pin maps;
- proprietary component strategy;
- firmware secrets;
- manufacturing packages.
