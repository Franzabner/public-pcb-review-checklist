# Public Boundary

Status: Scaffolded. Human Review Required before publication.

## Public-Safe

- generic PCB review checklist;
- synthetic examples;
- report templates;
- evidence and severity models;
- documentation gap categories;
- generic KiCad-adjacent review questions;
- public-safe interface and power-domain review prompts.

## Private Or Sealed

- client files;
- production schematics, layouts, routing, BOMs, Gerbers, exact pin maps;
- proprietary component strategy;
- production firmware links or private protocols;
- production RIB implementation or product lineage;
- customer data;
- certification or engineering sign-off claims;
- manufacturing release packages.

## Rule

Any real PCB artifact stays outside this repo unless it is explicitly reviewed and approved for public use. If an artifact could reconstruct a private board, production design, customer system, or sealed product strategy, it remains private or sealed.
